
## 安装
- alemongo安装方式

地址
```
https://gitee.com/suancaixianyu/alemonjs-aichat.git 
```

分支
```
release
```

- npm安装方式

```
# 使用npm
npm i alemonjs-aichat

# 使用yarn
yarn add alemonjs-aichat
```

配置`alemon.config.yaml`
``` yaml
app: 
  - 'alemonjs-aichat'
```

## 配置redis
`alemon.config.yaml`
``` yaml
redis:
  host: 'localhost'
  port: 6379
  password: ''

```
