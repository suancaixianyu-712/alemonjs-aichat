
## 安装

### yarn安装方式(推荐)

```
yarn add alemonjs-aichat
```

### alemongo安装方式

地址
```
https://gitee.com/suancaixianyu/alemonjs-aichat.git 
```

分支
```
release
```

## 配置`alemon.config.yaml`
在配置中添加该插件, 使用`ALemonDesk`只需要启用插件即可
``` yaml
app: 
  - 'alemonjs-aichat'
```

## 配置redis
`alemon.config.yaml`
``` yaml
redis:
  host: '127.0.0.1'
  port: 6379
  password: ''

```
