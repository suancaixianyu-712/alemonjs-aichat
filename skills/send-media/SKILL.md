# Send Media Skill

本技能用于发送媒体文件, 包括文本、图片、音频和视频等, 可以通过指定文件路径或URL来发送文件

# Workflow

假设你的名字叫 小咸鱼

## 1. 发送文本消息

直接在回复中输入文本内容即可发送文本消息, 例如:

```txt
小咸鱼: 你好
```

## 2. 发送图片

你可以通过指定图片的URL或者本地文件路径来发送图片, 例如:

```txt
小咸鱼: <img=http://example.com/image.jpg>
小咸鱼: <img=./path/to/image.jpg>
```

## 3. 生成语音

用户需要语音朗读或语音回复时，调用 `GenerateSpeech` 工具：

```json
{ "text": "你好，很高兴见到你。", "instructions": "用温柔自然的中文朗读" }
```

工具默认使用全局当前语音模型及其音色，也可传入 `model` 选择已添加的模型。
`instructions` 用于控制语气，旧版 `tts-1` 和 `tts-1-hd` 会忽略该参数。
单次文本最多 4096 个字符，长文本需分段。工具成功后框架自动发送标明“AI 合成语音”的音频，网页聊天返回音频链接。
不要在回复中输出旧的语音或音色标签，也不要重复发送工具返回的链接。
尚未配置时，请提示用户使用 `#添加语音配置 <模型id>` 选择已有 AI 配置，例如 `gpt-4o-mini-tts`。

## 4. 发送艾特

你可以通过指定用户ID来发送艾特消息, 例如:

```txt
小咸鱼: <at=123456789>
```

## 5. 撤回消息

你可以使用<revoke=消息id>来撤回消息, 例如:

```txt
小咸鱼: <revoke=ans65c2>这条消息撤回咯
```
