## 问题描述
编译失败，错误信息：
1. `Circular dependency: src/api/aitools.ts -> src/config.ts -> src/api/aitools.ts`
2. `"default" is not exported by "src/redis.ts", imported by "src/config.ts"`
3. `"redis" is not exported by "src/config.ts", imported by "src/api/aitools.ts"`

---

## 问题原因
循环依赖和导入方式不匹配：
1. `src/config.ts` 使用 `import redis from "./redis"`（默认导入）
2. `src/redis.ts` 导出的是命名导出 `export const redis`
3. `src/userEnv.ts` 导入 `redisClient from "./config"`（默认导入 config，但 config 没有导出 redis）
4. `src/api/aitools.ts` 导入 `redisClient from "@src/config"`（默认导入 config，但 config 没有导出 redis）

---

## 修复方案

### 1. 修复 `src/config.ts`
```typescript
// 修改前
import redis from "./redis";
// 修改后
import { redis } from "./redis";
```

### 2. 修复 `src/api/aitools.ts`
```typescript
// 修改前
import redisClient from "@src/config";
// 修改后
import { redis as redisClient } from "../redis";
```

### 3. 修复 `src/userEnv.ts`
```typescript
// 修改前
import redisClient from "./config";
// 修改后
import { redis as redisClient } from "./redis";
```

### 4. 修复 `tsconfig.json`
```json
// 修改前
{
  "compilerOptions": {
    "moduleResolution": "node",
    "types": ["node"],
    "ignoreDeprecations": "6.0",
    "paths": { "@src/*": ["./src/*"] }
  }
}

// 修改后
{
  "compilerOptions": {
    "moduleResolution": "bundler",
    "paths": { "@src/*": ["./src/*"] }
  }
}
```
